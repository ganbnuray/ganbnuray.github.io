# nurayg.me

Personal site of Nuray Ganbarova, styled as a terminal session. Built with
[Astro](https://astro.build) and deployed to GitHub Pages on every push to `main`.

## Run locally

Requires Node 22 or newer.

```sh
npm install
npm run dev
```

Then open http://localhost:4321.

## Content

| What | Where |
|---|---|
| Intro, facts, links, photos, interests | `src/data/site.ts` |
| Experience | `src/data/experience.ts` |
| Projects | `src/content/projects/*.md` |
| Research | `src/data/research.ts` |
| Cities | `src/data/elsewhere.ts` |
| Images | `photos/` |
| Colors | top of `src/styles/global.css` |
